# Restauration

## Nos repas

Trois repas équilibrés sont servis chaque jour, plus une collation l'après-midi. Nos menus sont élaborés par une nutritionniste et préparés par une équipe de cuisiniers professionnels.

## Horaire des repas

| Repas | Heure |
|-------|-------|
| Déjeuner | 7h30–8h30 |
| Dîner | 12h00–13h00 |
| Souper | 17h30–18h30 |
| Collation | 15h00 |

## Restrictions alimentaires

Nous accommodons les restrictions suivantes — veuillez les indiquer lors de l'inscription :

- :material-check: Végétarien
- :material-check: Végétalien
- :material-check: Sans gluten
- :material-check: Sans noix
- :material-check: Sans produits laitiers
- :material-check: Halal
- :material-check: Casher (sur demande préalable)

!!! warning "Allergies sévères"
    Pour les allergies anaphylactiques, veuillez joindre un plan d'action médical lors de l'inscription. L'équipe est formée à l'utilisation de l'EpiPen.
