## Nous trouver

Le Camp Bruchési est situé à **Saint-Hippolyte**, dans les Laurentides, sur le bord du **lac de l'Achigan**.

**50, 365e Avenue, Saint-Hippolyte, QC  J8A 2Y6**

**Accès :**

- Depuis Montréal : autoroute 15 Nord → sortie Saint-Jérôme → route 158 vers Saint-Hippolyte
- Depuis Saint-Jérôme : route 158 Est jusqu'à Saint-Hippolyte, suivre les indications
